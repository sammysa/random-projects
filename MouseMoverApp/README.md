#MouseMoverApp

**MouseMoverApp** — This app is a simple application that "moves your mouse" virtually through memory - a random project that is essentially created to make your machine think that you are still there

You can run the application on any IDE or straight through your compiler, I don't think that one would have any restrictions. Note that the MouseMover 'moves' your mouse in a random timing between
**10-59 seconds**, you can modify this time to your liking. The movements will be logged through terminal.
